# SpriteAnimations3D

A set of animations that can be used on 3D sprites

## Installation

Make sure to download the ChillCube Developer tools: https://github.com/ChillCube/ChillCube-Developer-Tools.git

### Using the Godot Plugin
Enable the **ChillCube Tools** plugin, then paste the repo URL into the Clone tab.

### Linux / CLI
```bash
clone-gd-addon https://github.com/ChillCube/SpriteAnimations3D.git
```

## Documentation
https://github.com/ChillCube/SpriteAnimations3D/blob/main/DOCUMENTATION.md

## Deinstallation
Use the CC Tools panel in Godot, or run:
```bash
remove-gd-addon SpriteAnimations3D
```

## For Developers

push-all-addons
